The MiniFASNet models from Silent Face Anti-Spoofing are specifically trained for **3-class classification**, not binary real/fake detection. The models classify between different types of attacks: print attacks (photo spoofing), replay/video attacks, and real faces.

**Your output is correct:**
- **3 values**: This is the intended design
- **Class 0**: Real/Live face  
- **Class 1**: Print attack (photo spoof)
- **Class 2**: Replay/Video attack

**To get binary real/fake detection:**

```python
def interpret_antispoof_output(class_probabilities, threshold=0.5):
    """
    Convert 3-class output to binary real/fake decision
    """
    real_prob = class_probabilities[0]  # Class 0 = Real
    spoof_prob = class_probabilities[1] + class_probabilities[2]  # Print + Replay
    
    is_real = real_prob > threshold
    confidence = real_prob if is_real else spoof_prob
    
    return is_real, confidence, {
        'real': class_probabilities[0],
        'print_attack': class_probabilities[1], 
        'replay_attack': class_probabilities[2]
    }

# Your example:
probs = [0.0004, 0.007, 0.9925]
is_real, confidence, details = interpret_antispoof_output(probs)
print(f"Real: {is_real}, Confidence: {confidence:.3f}")
print(f"Attack type: {'Replay attack' if details['replay_attack'] > details['print_attack'] else 'Print attack'}")
```
